# NoteHub

NoteHub is a workspace for organizing, editing, and searching notes and documents.

## Documentation

- [Authoring documents in NoteHub](docs/markdown.md) covers Markdown, links, diagrams, and embedded media.

## Services

Each service keeps its release version in a `VERSION` file inside its own directory.

- [Renderer](services/renderer/) renders D2 source to SVG over HTTP.
